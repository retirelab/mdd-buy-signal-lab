# 차트 확대 보기

모멘텀, 낙폭, 가격 흐름 차트의 `크게 보기` 버튼으로 화면을 채우는 팝업을 엽니다.

- HTML dialog와 React portal로 팝업을 본문에 표시합니다. 원래 카드의 잘림과 중첩 순서 영향을 받지 않습니다.
- 확대 시 원래 차트 높이의 자리 표시자를 두고 배경 스크롤을 잠급니다. 닫으면 배경 스타일과 버튼 포커스를 복원합니다.
- 기본 확대 팝업은 브라우저의 Fullscreen API 없이도 동작합니다.
- Fullscreen API를 지원하면 `브라우저 전체화면` 버튼을 표시합니다. 전환이 거절되면 확대 팝업을 유지하고 안내합니다.
- 닫기 버튼, Esc, 브라우저의 dialog 닫기 요청을 처리합니다. 팝업이 연 전체화면은 닫을 때 정리합니다.
- 모멘텀은 선택한 표시 기간을 유지하고 날짜를 조회합니다. 가격과 낙폭은 원본 일별 자료의 날짜 선택을 공유합니다.
- 팝업 차트 높이는 화면 높이에 맞춰 조절됩니다. 작은 화면에서는 내용 부분을 스크롤할 수 있고 닫기 버튼은 상단에 유지됩니다.

검증: Node 회귀 테스트 54개, 브라우저에서 세 차트 확대·날짜 조회·Esc 닫기·포커스와 스크롤 복원, 모바일 폭 390px / 높이 800px에서 팝업·차트 크기 및 날짜 조회 확인.
