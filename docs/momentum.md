# 60일 / 200일 추세추종 모멘텀

- USD 일별 가격의 단순이동평균(SMA)을 사용합니다. 60개 / 200개의 유효 거래일 가격을 각각 평균합니다.
- 차트 시작일 이전 데이터로도 평균을 준비하고, 분석 종료일 이후 자료는 사용하지 않습니다.
- 현재 상태(60일선이 위 / 아래 / 동일)와 교차 이벤트를 구분합니다.
- 최초로 200일 평균이 계산되는 날에는 교차를 추정하지 않습니다. 관측된 두 선의 우위가 뒤바뀔 때 골든 / 데드크로스를 기록합니다.
- 두 선이 같은 동안은 마지막 우위를 유지합니다. 선에 닿았다가 같은 쪽으로 되돌아오면 새 교차가 아닙니다. 수치 오차는 상대 간격 1e-12로 처리합니다.
- 최근 교차 날짜와 경과 거래일 수는 저장된 종가 기록에서 계산합니다. 조회 시세를 적용한 화면용 시계열은 별도로 계산하여 잠정 상태 / 잠정 교차로 표시합니다.
- 같은 거래일의 조회값은 마지막 가격만 교체하여 평균에 하루가 중복되지 않습니다. 새 거래일은 화면에 임시로 추가합니다.
- 조회값이 되돌아가면 잠정 교차는 사라집니다. 확정 종가 파일과 과거 회복 통계는 수정하지 않습니다.
- 차트는 최근 최대 252거래일의 가격과 60 / 200일선을 표시합니다. 날짜 선택 및 가로 드래그로 조회하며 세로 터치는 스크롤을 유지합니다.
- 두 선의 간격은 SMA60 / SMA200 - 1입니다. 가격의 이동평균 대비 거리와 구분합니다.
- 기존 낙폭 / 공포 조건의 통과 수에는 이 지표를 추가하지 않습니다.

통상적인 50 / 200일 교차와 같은 원리를 사용자 요청의 60 / 200일에 적용한 지표입니다. 교차는 후행하며 횡보 중 반복될 수 있습니다.
