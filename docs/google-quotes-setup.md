# Google Finance 시세 연결

앱을 열거나 **현재가 새로고침**을 누르면 Google 시트에 제공된 최신 가격을 읽습니다.
Google 자체 시세 갱신을 강제하지 않으며 최대 20분 지연될 수 있습니다.
현재가 응답은 브라우저 메모리에만 보관합니다. 기존 종가 기록 스케줄과 과거 통계는 변경하지 않습니다.

## 한 번만 설정

1. 본인 Google 계정으로 [새 Apps Script 프로젝트](https://script.google.com/home/start)를 엽니다.
2. 이 저장소의 [`scripts/google_quotes.gs`](../scripts/google_quotes.gs)를 복사해 `Code.gs` 전체에 붙여넣고 저장합니다.
3. 함수 선택에서 `setup`을 실행하고 권한을 확인합니다. **이 스크립트는 시세 전용 새 시트를 생성합니다.** 기존 자산관리 시트나 계좌 내역을 넣지 마세요.
4. 실행 로그에 나온 시트를 열어 Quotes 탭에 가격과 거래 시각이 표시되는지 확인합니다. Google 수식 초기 로딩에는 시간이 걸릴 수 있습니다.
5. **배포 → 새 배포 → 웹 앱**을 선택합니다. 실행 사용자: **본인**, 액세스: **모든 사용자**로 배포합니다. 이 주소는 누구나 시세 데이터만 읽을 수 있는 공개 주소입니다. 비밀번호나 API 키, 계좌 데이터는 넣지 마세요.
6. 생성된 `https://script.google.com/macros/s/…/exec` 주소를 복사합니다.
7. RetireLab 앱의 **현재 제공 시세 → 시세 연결 설정**에 주소를 넣고 **연결하고 조회**를 누릅니다.

주소는 해당 브라우저에만 저장됩니다. 다른 기기에서는 같은 주소를 다시 등록합니다.
공개 앱의 모든 사용자에게 기본 연결하려면 배포 주소를 확인한 뒤 별도의 기본 설정으로 적용해야 합니다.

## 읽는 값

- SPY, QQQ, HYG, GLD, TLT: price, tradetime, datadelay, closeyest, currency
- 원·달러 환율: CURRENCY:USDKRW
- `tradeAt`: Google이 제공한 거래 시각
- `readAt`: 스크립트가 셀을 읽은 시각이며, Google 원천 자료의 갱신 시각이 아닙니다.
- 환율은 원천 거래 시각을 검증할 수 없어 ‘조회 환율로 환산’으로 표시합니다.

미국 증시가 닫혀 있으면 최근 거래 시세가 반환될 수 있습니다. 새로고침해도 가격이 그대로일 수 있습니다.
과거 GOOGLEFINANCE 데이터는 Apps Script 접근 제한이 있으므로 이 코드는 날짜 인자가 없는 현재 시세만 읽습니다.

## 종가와 조회 시세 구분

- 앱 진입 또는 새로고침으로 받은 시세는 현재가·현재 낙폭·매수 조건과 두 차트 마지막 지점에 반영합니다.
- 같은 미국 거래일이면 마지막 지점의 화면용 복사본만 대체합니다. 새 거래일이면 화면에만 임시 지점을 추가합니다. 종가 JSON과 자동 저장 스케줄은 변경하지 않습니다.
- 과거 회복 통계와 과거 사례 확대는 확정 종가 자료만 사용합니다.
- 주가와 환율의 관측 시각이 다를 수 있으므로 원화는 ‘조회 환산가’로 표시합니다. 미국 장이 닫혀 있으면 달러 가격은 최근 거래일 가격과 같더라도 환율에 따라 원화 표시가 달라질 수 있습니다.
- 거래일은 미국 뉴욕 시간대로 판단합니다. 주말이라는 이유만으로 이미 저장된 최근 거래일 시세를 무효화하지 않습니다.
- 적용 조건: 선택 종목 일치, 분석 종료일 이내, 저장된 마지막 거래일 이상, 최근 종가와 기준 가격 차이 0.5% 이내. 최근 종가와 새 거래일 간격이 7일을 넘으면 오래된 자료로 간주하고 적용을 보류합니다.
- 새 거래일의 기준 가격 검사는 Google 제공 전일 종가로, 같은 거래일은 Google 제공 가격으로 확인합니다. 이 검사는 완전한 분할·배당 검증을 대신하지 않습니다.
- 데이터가 없거나 가격 기준이 맞지 않으면 해당 통화는 종가 화면을 유지합니다. 원화 시세는 유효한 환율이 있을 때만 반영합니다.
- 조회 실패 시 마지막으로 성공한 조회값을 표시하고 실패 안내를 붙입니다.
- Google 데이터의 이용·공개 재배포 조건은 별도 확인 대상입니다. 기술적 연결 가능성이 사용 허가를 뜻하지 않습니다.

## 업데이트

Apps Script 코드를 바꾼 뒤에는 기존 배포를 새 버전으로 업데이트해야 같은 /exec 주소에 반영됩니다.
시트 수식만 변경한 경우에는 웹앱 코드를 다시 배포하지 않아도 됩니다.
