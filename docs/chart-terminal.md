# 금융 차트 UI

v2026.11.11.4부터 TradingView Lightweight Charts 5.1.0의 선차트를 사용합니다. CDN 버전을 고정하고 기존 SVG를 대체 차트로 보관합니다.

- 종가 / 화면용 조회 시세와 원래 계산된 이동평균, 원본 일별 낙폭을 사용합니다. OHLC와 거래량을 생성하지 않습니다.
- 오른쪽 가격 눈금, 현재값 라벨과 점선, 거래일 가로축, 세밀한 격자, 십자선을 표시합니다.
- 모멘텀의 60 / 200일선은 각각 표시를 전환할 수 있습니다. 가격과 이동평균 수치는 선택 날짜로 동기화합니다.
- 가격 차트에서 선형 / 로그 축을 전환합니다. 낙폭 차트는 선형 퍼센트 축을 사용하며 목표선과 0%를 표시 범위에 포함합니다.
- 확대 / 축소 / 전체 구간 버튼, 가로 드래그 이동, 두 손가락 확대를 제공합니다. 휠 확대는 확대 팝업에서만 사용하여 기본 화면의 세로 스크롤을 유지합니다.
- 상단의 기간 선택은 입력 자료의 기간을 바꿉니다. 차트 안의 확대·이동은 그 안의 표시 구간을 바꾸며 하단에 실제 화면 구간을 표시합니다.
- 가격 / 낙폭 차트의 날짜 선택은 공유합니다. 사례 표시와 조회 시세 지점도 원본 날짜에 붙입니다.
- 이동평균 계산 및 과거 회복 통계는 기존 엔진을 사용합니다. 차트용 입력 정렬·중복 날짜 처리·결측값·마커 처리는 chart-terminal.js에서 관리합니다.
- 팝업이 표시되기 전에 차트 크기가 0인 경우 십자선 초기화를 다음 프레임으로 미룹니다. ResizeObserver와 컴포넌트 정리 시 이벤트·차트 객체를 제거합니다.
- CDN을 불러오지 못하면 기존 SVG 차트와 날짜 조회를 유지합니다.

Apache 2.0 라이선스와 NOTICE는 docs/third-party에 보관합니다. 차트의 TradingView 로고 / 링크와 앱 하단의 저작권 표시를 유지합니다.

검증: `node --test tests/*.test.cjs`, 브라우저에서 세 차트·기간 변경·로그 축·MA 토글·확대와 복원·날짜 및 십자선 연동·모바일 폭·대체 차트 확인.
